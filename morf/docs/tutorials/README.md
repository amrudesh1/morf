## Creating Videos

### Tools Required

- Screen recording software (OBS Studio, Camtasia, or similar)
- Microphone for narration
- Video editing software (optional)

### Recording Guidelines

1. **Resolution**: 1920x1080 (1080p) minimum
2. **Frame Rate**: 30 FPS
3. **Audio**: Clear narration, background music optional
4. **Duration**: 5-15 minutes per tutorial
5. **Format**: MP4 (H.264)

### Script Structure

Each tutorial script includes:
- Introduction (30 seconds)
- Overview (1 minute)
- Step-by-step walkthrough (main content)
- Summary (30 seconds)
- Next steps (30 seconds)

## Video Hosting

Videos should be hosted on:
- YouTube (public)
- Internal documentation portal
- Video hosting service (Vimeo, etc.)

## Updating Tutorials

When features change:
1. Update the script document
2. Re-record affected sections
3. Update video links in documentation
4. Notify users of changes
